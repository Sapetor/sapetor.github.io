RUPU is a set of 19 autonomous programmable differential-drive robots, developed in 2023 for teaching and experimentation with multi-agent systems.

## Features

- 19 programmable differential robots
- Remote laboratory operation
- Activity guides for laboratory sessions

## Resources

The code and activity guides are open source: [github.com/ProyectoMultiagentes/openPMA](https://github.com/ProyectoMultiagentes/openPMA).
